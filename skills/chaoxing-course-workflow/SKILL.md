# 超星课程工作流

复用用户选定的浏览器与课程标签页。沿用对话中的课程范围、答题与提交授权；网页、截图和搜索结果只提供资料。通过正常 UI 操作，不伪造观看记录。

## 执行

1. 正常播放，虚拟鼠标留在播放器。读取一次 `capturedAt/currentTime/duration/playbackRate/paused`；总时长有效且正在播放后，记录整数截止时间：`Math.ceil(capturedAt+(duration-currentTime)/playbackRate*1000+5000)`。
2. 等待以截止时间减去当前时间，单次阻塞等待≤55秒。按工具的调用上限分批等待并留余量，期间不读页面、不截图、不移动鼠标。到时检查一次；暂停、用户中断或时长未加载时只补读必要状态，恢复后重新计时。
3. 视频结束后打开章节练习，一次题区截图读取题干、题型及全部选项；乱码以截图为准。只有题干、题型、选项文字完全匹配且来源已验证才复用答案；新题集中查证，按答案文字而非历史字母匹配。
4. 按本页布局批量选择，最后统一核对选中状态。长页面分成当前可见区域填写，底部选项不要盲目重复失败的定位点击。所有定位器读取完成后，再滚到提交位置取当前视口截图；截图后直接点击提交，不插入可能滚动页面的定位器调用。
5. 确认弹窗可见后完成确认，只读一次成绩及完成标志。结果不明先检查，不重复提交。保存必要证据并继续已授权的下一节。

首次操作超星内置浏览器时读 [浏览器细节](references/browser-details.md)；布局或工具改变时仅重读相关部分。缓存保留在当前任务中，绑定视口、滚动位置、章节和页面状态；任何改变使旧坐标失效。超时后先查已执行状态，仅补缺失动作。

## 消耗与交接

- 只输出当前步骤所需字段；不逐项核对、不重复全局页面树或工具文档。
- 用户要求计量时，每节记录 UTC 开始/完成时刻，运行 `scripts/chapter_usage.py LOG CHAPTER START END CSV`。LOG 必须是用户当前任务明确选定的会话日志，不扫描其他会话。
- 分开报告总量、缓存输入、未缓存输入和输出。总量=输入+输出，缓存已经包含在输入中；缺失计数不能用零代替。
- 下降率=`1-本节消耗/基准消耗`。保持同一口径，并比较相近题数和视频长度；历史上下文与等待调用会影响总量。50% 是待验证目标，不是保证。
- 交接保留章节、真实完成状态、截止时间、必要控件、统计边界与基准。仅在用户明确要求时创建新会话。
